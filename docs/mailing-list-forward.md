# メーリングリストへの転送設定

## 運用の流れ

```
毎週月曜 07:00  GitHub Actions が Gmail からニュースを送信
       ↓
fujita-t@andex.co.jp に届く（PC の Outlook）
       ↓
毎週月曜 11:00  転送スクリプト or 手動転送
       ↓
社内メーリングリストに配信
```

さくらのメールサーバーは外部（GitHub / Gmail）からの直接送信を拒否するため、
**社内アドレス経由の転送**で配信します。

---

## 事前準備

### 1. GitHub Secrets の `NOTIFY_EMAIL`

自分宛てのみに設定してください。

```
fujita-t@andex.co.jp
```

### 2. `.env` に転送先を追加

```
MAILING_LIST_EMAIL=メーリングリストのアドレス@andex.co.jp
# 複数指定する場合（カンマ区切り）:
# MAILING_LIST_EMAIL=gijutsu_ml@andex.co.jp,sekkei_ml@andex.co.jp,eigyo_ml@andex.co.jp
SUBJECT_KEYWORD=塗装業界ニュース
FORWARD_INTRO_TEMPLATE={month}月{day}日の業界ニュースです。
NOTIFY_EMAIL=fujita-t@andex.co.jp
```

---

## 方法A: 毎週月曜 11:00 に自動転送（推奨）

### 手順

1. **Outlook を起動した状態**にしておく（常駐で問題ありません）
2. タスクスケジューラを開く（`taskschd.msc`）
3. **タスクの作成** をクリック
4. 以下のように設定する

| 項目 | 設定値 |
|------|--------|
| 名前 | 塗装業界ニュース ML転送 |
| トリガー | 毎週 / 月曜日 / 11:00 |
| 操作 | プログラムの開始 |
| プログラム/スクリプト | `C:\Users\fujita-t\ツール\塗装業界ニュース\scripts\run_forward.bat` |
| 引数の追加 | **空欄のまま** |
| 開始 | **空欄のまま** |
| 条件 | 「コンピューターを AC 電源で使用している場合のみ」は**オフ** |
| 設定 | 「タスクが失敗した場合の再起動間隔」を 10分に設定（任意） |

> **注意:** 以前の手順で「開始」欄に `|` が入ると失敗します。`run_forward.bat` を使えば回避できます。

### テスト実行

```powershell
cd "C:\Users\fujita-t\ツール\塗装業界ニュース"
.\scripts\forward_news_email.ps1 -DryRun
```

実際に転送する場合:

```powershell
.\scripts\forward_news_email.ps1
```

### 注意点

- **PC が月曜 11:00 に起動している必要があります**
- Outlook が起動していないと転送できません
- 7:00 前後に届いたメールを、当日 11:00 に転送します
- 転送メールの冒頭に「6月15日の業界ニュースです。」のようなメッセージが付きます

### 自動リトライについて

GitHub Actions のスケジュール実行は混雑時に数十分〜数時間ずれることがあり、
実行時点でまだニュースメールが届いていない場合があります
（2026-08-31 に実際に発生。通常 07:27 完了のところ 09:20 完了）。

そのため、対象メールが見つからない場合は **10分間隔で最大90分** 再検索します。
再検索のたびに Outlook の送受信も実行します。

| パラメータ | 既定値 | 説明 |
|------|--------|------|
| `-MaxWaitMinutes` | 90 | 最大待機時間（分） |
| `-RetryIntervalMinutes` | 10 | 再検索の間隔（分） |

転送に成功するとプロジェクト直下の `.forward-state` に当日日付が記録され、
同じ日に再実行しても二重送信されません（手動転送とリトライが重なった場合の保険）。
`-DryRun` はこの記録を読み書きしません。

## 方法B: 手動転送（確実）

毎週月曜、ニュースメールを開いて **転送** ボタンからメーリングリストへ送る方法です。

1. `fujita-t@andex.co.jp` の受信トレイを開く
2. 件名に「塗装業界ニュース」とあるメールを選択
3. **転送** → メーリングリストのアドレスを入力 → 送信

所要時間は約30秒です。

## トラブルシューティング

| 症状 | 対処 |
|------|------|
| 「本日受信したメールが見つかりません」 | 90分リトライしても届かなかった状態。GitHub Actions の実行が失敗していないか確認し、必要なら手動転送 |
| Outlook に接続できない | Outlook を起動してから再実行 |
| 転送は成功したが ML に届かない | メーリングリストのアドレスを再確認。社内メール管理者に問い合わせ |
| 同じニュースが2通届いた | `.forward-state` が消えている可能性。ファイルの有無を確認 |

### タスクスケジューラの「前回の実行結果」の読み方

表示される値は Windows のエラーコードではなく、スクリプトが返した終了コードです。

| コード | 意味 |
|------|------|
| `0x0` | 正常終了（転送成功、または当日転送済みでスキップ） |
| `0x1` | Outlook に接続できない、`.env` の設定不足 |
| `0x2` | リトライしても当日のニュースメールが見つからなかった |
